01 / DISCOVER

Metadata is an index, not a verdict.

Search title, tags, ids, source paths and revision evidence. Availability and evidence remain separate dimensions.

02 / INSPECT

Evidence stays on its own axis.

Recorded availability, revisions, receipts and runtime state remain separate so weak metadata cannot inherit stronger trust.

03 / COLLECT

Intent precedes persistence.

Catalog pins are references. Selected JSON is staged in memory, reviewed, then explicitly added or discarded.

04 / PEER

Sessions are explicit. Handoff stays gated.

Create or join a private capability-derived lobby. Artifact offers still require negotiated support, a content digest, bounded size, and healthy current transport evidence.
