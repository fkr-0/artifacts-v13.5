# V13.5 Product Contract

## Primary user journey

V13.5 is a launcher first:

1. arrive at the complete artifact catalog;
2. search or filter;
3. inspect details only when useful;
4. open the artifact directly.

No collection/import ceremony gates launch.

## Favorites

Favorites are a small browser-local convenience. They store stable artifact IDs only and can filter the catalog. Failure to persist a Favorite must not make an artifact unavailable.

## Evidence

Provenance, build mode, deployment state, Git revision, and changed date remain inspectable in each card's Details disclosure. They support user judgment without becoming the landing-page hierarchy.

## Accessibility

The launcher includes a skip link, semantic filter labels, live result status, visible focus, keyboard-native controls, reduced-motion handling, and responsive one-column fallbacks.
